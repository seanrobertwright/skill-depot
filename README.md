# Skill Deport

A one-command installer for Claude Code skills.

`skills.sh` lets users drop skills into any project without manual cloning, copying, or wiring — simplifying the skill setup process.

## Status

Early scaffolding. See `.archon/` for workflow definitions.

## Usage (planned)

```bash
# Install a skill into the current project
./skills.sh add <skill-name>

# List installed skills
./skills.sh list

# Remove a skill
./skills.sh remove <skill-name>
```
